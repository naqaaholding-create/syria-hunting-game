# Migration 002 — قاعدة البيانات المالية

هذه الترحيلة تضيف أساسًا لتسجيل الدخول وجلسات الخادم، ربط عناوين TRON، أحداث إيداع USDT، مؤشر الماسح، وسجلات تحويل السحب اليدوي. كما تضيف فحصًا مؤجلًا لتوازن معاملات دفتر الأستاذ ومنع تعديل/حذف القيود التابعة لمعاملة مرحلة.

## التشغيل المحلي

بعد ضبط `DATABASE_URL` في ملف `.env` المحلي، راجع الترحيلة ثم نفّذها على قاعدة تطوير فارغة أو نسخة احتياطية:

```sh
psql "$DATABASE_URL" -v ON_ERROR_STOP=1 -f backend/schema/financial_schema.sql
psql "$DATABASE_URL" -v ON_ERROR_STOP=1 -f backend/migrations/002_auth_chain_ledger.sql
```

لا تنفذها على قاعدة إنتاج قبل مراجعة DBA وتجربة الاسترجاع. لا تضع بيانات الاتصال في الأوامر التي تُحفظ في سجل مشترك أو في GitHub.

## حدود المرحلة

- الجداول لا تنشئ حسابات دخول وحدها؛ يجب إضافة التسجيل وتجزئة كلمات المرور وتحديد المعدل واسترداد الحساب بأمان.
- أحداث السلسلة ليست مصدرًا موثوقًا لمجرد إدخالها إلى الجدول؛ يجب أن تأتي من ماسح موثوق يتحقق من العقد والعنوان والنجاح والتأكيدات ويعيد المصالحة.
- لم تتم إضافة توقيع آلي للتحويلات، ولا ينبغي أن يحمل خادم الويب مفتاح محفظة.
- جميع وظائف الإيداع والسحب تبقى معطلة حتى إكمال الاختبارات ومراجعة الأمان.
