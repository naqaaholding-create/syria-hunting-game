# Migration 003 — حسابات دفتر الأستاذ النظامية

تضيف هذه الترحيلة حسابات مقابلة مملوكة للنظام حتى يمكن تمثيل المنح والمكافآت والتحصيل والمصروفات بقيود مزدوجة متوازنة، بدل استخدام حساب لاعب وهمي.

## قبل التشغيل
- نفّذها فقط بعد الترحيل 001 (financial_schema.sql) و002.
- اختبرها على قاعدة بيانات تطوير قابلة للحذف، ثم افحص القيود والفهارس قبل اعتمادها.
- لا تُنشئ هذه الترحيلة أموالًا فعلية؛ الأرصدة المحاسبية مجرد سجلات داخل قاعدة البيانات.
- يجب أن تستخدم خدمة الخادم فقط صلاحية الكتابة إلى دفتر الأستاذ، مع منع وصول العميل المباشر إلى قاعدة البيانات.

## الترتيب
```sh
psql "$DATABASE_URL" -v ON_ERROR_STOP=1 -f backend/schema/financial_schema.sql
psql "$DATABASE_URL" -v ON_ERROR_STOP=1 -f backend/migrations/002_auth_chain_ledger.sql
psql "$DATABASE_URL" -v ON_ERROR_STOP=1 -f backend/migrations/003_platform_ledger_accounts.sql
```

لم تُختبر هذه الترحيلات على قاعدة PostgreSQL حية في بيئة التطوير هذه؛ يلزم اختبارها محليًا قبل الانتقال لأي بيانات حقيقية.
