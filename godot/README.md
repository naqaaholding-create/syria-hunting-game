# رحلة صيد

مشروع لعبة صيد 3D في سورية.

## المحركات

- النسخة الحالية القديمة على GitHub Pages محفوظة كما هي.
- بدأنا الآن مسار **Godot 4** داخل مجلد `godot/`.
- الهدف: نقل المشروع تدريجيًا إلى محرك 3D حقيقي، مع الحفاظ على تصميم اللعبة ومحتواها.

## ما تم وضعه في بداية Godot 4

- مشروع Godot 4 قابل للفتح من Android Editor.
- Renderer: Compatibility.
- عالم 3D إجرائي بدون أصول خارجية.
- اختيار المحافظات السورية الـ14.
- مناطق أولية، ومنها **ذيبين في السويداء**.
- صياد + كلب صيد.
- أوامر الكلب: ابحث، تتبع، ثبت، توقف، تعال.
- حركة لمس بسيطة وحركة لوحة مفاتيح.
- كاميرا منظور ثالث.
- إضاءة وسماء وتضاريس نباتية أولية.

## المسار التالي

1. بناء خريطة 3D حقيقية لكل منطقة.
2. نظام الوقت والطقس.
3. ذكاء الكلب والتتبع.
4. الحيوانات والمطاردة.
5. الأسلحة والذخيرة.
6. الحفظ والتقدم.
7. الصوت المكاني والمؤثرات السينمائية.
8. تحسين الأداء للهاتف.

> المشروع القديم لا يتم حذفه؛ Godot 4 يبدأ بجانب النسخة الحالية داخل المستودع.
