# رحلة صيد

لعبة صيد ثلاثية الأبعاد للويب، تعمل على GitHub Pages.

## الحالة الحالية
- عالم 3D عبر Three.js مع وضع توافق 2D.
- اختيار المحافظات والمناطق.
- طقس ووقت محليان.
- خمسة كلاب وصلاحيات أوامر ميدانية.
- تتبع وآثار وأحداث ميدانية.
- طريدة مخفية وسلوك هروب.
- HUD للبوصلة والرياح والطاقة والذخيرة.
- دورة نهار/ليل وتأثيرات الطقس.
- حفظ حالة الرحلة وموقع اللاعب.
- PWA وService Worker.
- إحصائيات الرحلات والاكتشافات.

## مراحل لاحقة
1. تحسين التضاريس والبيئات الإقليمية.
2. نماذج حيوانات وكلاب ثلاثية الأبعاد حقيقية.
3. أصوات وخطوات ونداءات حيوانات.
4. نظام مهمات وتقدم.
5. خريطة إقليمية تفاعلية.
6. Multiplayer وVoice بعد اكتمال النسخة الفردية.
7. Backend آمن للميزات التي تحتاج خادمًا.
